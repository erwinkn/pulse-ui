`pulse-pandas` sends Pandas and NumPy values to Pulse components without adding
those dependencies to the core framework.

## Installation

```bash
uv add pulse-pandas
```

## Install the plugin

```python
import pandas as pd
import pulse as ps
from pulse_pandas import PulsePandas


frame = pd.DataFrame(
    {
        "product": ["Keyboard", "Mouse"],
        "revenue": [1200, 850],
    }
)

app = ps.App(plugins=[PulsePandas()])
```

DataFrames use records by default:

```json
[
  {"product": "Keyboard", "revenue": 1200},
  {"product": "Mouse", "revenue": 850}
]
```

Use `dataframes="columns"` for the compact column-oriented format:

```python
app = ps.App(plugins=[PulsePandas(dataframes="columns")])
```

```json
{
  "columns": ["product", "revenue"],
  "rows": [["Keyboard", 1200], ["Mouse", 850]]
}
```

Both formats preserve order and omit the DataFrame index. Use `series.to_dict()`
when the index matters. Column names must be unique strings.

`Series`, `Index`, `ndarray`, and Pandas extension arrays become lists.
`DatetimeIndex` and `MultiIndex` are supported. NumPy scalars become Python
scalars, timestamps follow Pulse's temporal convention, and `None`, `NaN`,
`pd.NA`, and `NaT` become `null`. Infinity remains invalid.

`pd.Timedelta`, `np.timedelta64`, `pd.Period`, `pd.Interval`, and NumPy complex
scalars are rejected with suggested conversions. The projection is one-way:
the browser receives JavaScript values, never a DataFrame or other Pandas
object.
