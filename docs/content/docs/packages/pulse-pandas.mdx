`pulse-pandas` sends Pandas and NumPy values to Pulse components without adding
those dependencies to the core framework.

## Installation

```bash
uv add pulse-pandas
```

## Install the plugin

```python
import pandas as pd
import pulse as ps
from pulse_pandas import PulsePandas


frame = pd.DataFrame(
    {
        "product": ["Keyboard", "Mouse"],
        "revenue": [1200, 850],
    }
)

app = ps.App(plugins=[PulsePandas()])
```

DataFrames use records by default:

```json
[
  {"product": "Keyboard", "revenue": 1200},
  {"product": "Mouse", "revenue": 850}
]
```

Use `dataframes="columns"` for the compact column-oriented format:

```python
app = ps.App(plugins=[PulsePandas(dataframes="columns")])
```

```json
{
  "columns": ["product", "revenue"],
  "rows": [["Keyboard", 1200], ["Mouse", 850]]
}
```

Both formats preserve order and omit the DataFrame index. Use `series.to_dict()`
when the index matters. Column names must be unique strings.

`Series`, `Index`, `ndarray`, and Pandas extension arrays become lists.
`DatetimeIndex` with `DatetimeTZDtype`, `MultiIndex`, and object arrays of
timezone-aware `Timestamp` values are supported. NumPy scalars become Python
scalars, timestamps follow Pulse's temporal convention, and `None`, `NaN`,
`pd.NA`, and `NaT` become `null`. Infinity remains invalid.

## Supported values

| Value | Wire projection |
|---|---|
| `pd.DataFrame` | Records by default, or `columns` format |
| `pd.Series` | List of values; index dropped |
| `pd.Index` | `tolist()`; includes `DatetimeIndex` and `MultiIndex` |
| `np.ndarray` | Lists, including nested arrays, `datetime64` arrays, and object arrays of timestamps |
| `ExtensionArray` | `tolist()`; includes categoricals and nullable arrays |
| `pd.Timestamp` | UTC-localized when naive, then timezone-aware timestamp with millisecond precision |
| `np.datetime64` | UTC-localized timestamp |
| NumPy scalar | Python scalar via `.item()` |
| `pd.NaT`, `pd.NA`, `NaN` | `null` |

Naive temporal values are interpreted as UTC by default. Temporal values use
exact millisecond precision. Pandas Series and indexes with `DatetimeTZDtype`
are supported; localize or convert them with `tz_localize` or `tz_convert`.
Object arrays containing timezone-aware `Timestamp` values and NumPy
`datetime64` values and arrays are supported.

`pd.Timedelta`, `np.timedelta64`, `pd.Period`, `pd.Interval`, and NumPy complex
scalars are rejected with suggested conversions. The projection is one-way:
the browser receives JavaScript values, never a DataFrame or other Pandas
object.

## Rejected values

| Value | Suggested conversion |
|---|---|
| `pd.Timedelta`, `np.timedelta64` | `.total_seconds()` or a formatted string |
| `pd.Period` | `str(period)` |
| `pd.Interval` | `str(interval)` |
| NumPy complex scalar | A real component or a formatted string |

Use `PulsePandas(naive_timestamps="reject")` to require explicit localization
of naive temporal values. In strict mode, localize values with
`.tz_localize("UTC")`, or use `.dt.tz_localize("UTC")` for a Series column.
