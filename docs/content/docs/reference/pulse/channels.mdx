Bidirectional communication channels for real-time messaging between server and client.

## Functions

### channel

```python
def channel(
    identifier: str | None = None,
    *,
    lifetime: Literal["route", "tab"] = "route",
) -> Channel
```

Create a channel for the current browser tab.

**Parameters:**
- `identifier` - Optional channel ID. Auto-generated UUID if not provided.
- `lifetime` - Automatic cleanup boundary:
  - `"route"` closes the channel when its route is destroyed. This is the default.
  - `"tab"` keeps the channel across route changes and closes it with the render session.

**Returns:** `Channel` instance.

**Raises:**

- `RuntimeError` if called outside an active render session.
- `RuntimeError` if a route-lifetime channel is created without an active route.
- `ValueError` if `lifetime` is not `"route"` or `"tab"`.

```python
import pulse as ps

@ps.component
def ChatRoom():
    ch = ps.channel("chat")

    @ch.on("message")
    def handle_message(payload):
        # Handle incoming message from client
        ch.emit("broadcast", payload)

    return ps.div("Chat room")
```

Use tab lifetime for state that survives route changes:

```python
class NotificationState(ps.State):
    def __init__(self):
        self.channel = ps.channel("notifications", lifetime="tab")
```

Either lifetime can end early with `channel.close()`. The render session is the
hard upper boundary for all channels, so a tab channel is not shared with other
tabs or users. A tab channel has no route owner, so its handlers run without a
current route context.

A subscribed client can send events while the channel is open.

## Classes

### Channel

Bidirectional communication channel bound to a render session.

#### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | `str` | Channel identifier |
| `render_id` | `str` | Associated render session ID |
| `session_id` | `str` | Associated user session ID |
| `lifetime` | `Literal["route", "tab"]` | Automatic cleanup boundary |
| `route_path` | `str \| None` | Route path this channel is bound to |
| `closed` | `bool` | Whether the channel is closed |
| `connected` | `bool` | Whether a browser bridge is currently subscribed |

#### Methods

##### on

```python
def on(self, event: str, handler: ChannelHandler) -> Callable[[], None]
```

Register a handler for an incoming event.

**Parameters:**
- `event` - Event name to listen for.
- `handler` - Callback function `(payload: Any) -> Any | Awaitable[Any]`.

**Returns:** Callable that removes the handler when invoked.

**Raises:** `ChannelClosed` if channel is closed.

```python
ch = ps.channel()

def cleanup():
    remove_handler()

remove_handler = ch.on("data", lambda payload: print(payload))
```

##### emit

```python
def emit(self, event: str, payload: Any = None) -> None
```

Send a fire-and-forget event to the client.

If no browser bridge is subscribed, Pulse buffers up to 64 events per channel. It
flushes them in order when the client subscribes again and drops the oldest event
when the buffer is full.

**Parameters:**
- `event` - Event name.
- `payload` - Data to send (optional).

**Raises:** `ChannelClosed` if channel is closed.

```python
ch.emit("notification", {"message": "Hello"})
```

##### request

```python
async def request(
    self,
    event: str,
    payload: Any = None,
    *,
    timeout: float | None = None,
) -> Any
```

Send a request to the client and await the response.

**Parameters:**
- `event` - Event name.
- `payload` - Data to send (optional).
- `timeout` - Timeout in seconds (optional).

**Returns:** Response payload from client.

**Raises:**
- `ChannelClosed` if channel is closed.
- `ChannelDisconnected` if no browser bridge is subscribed.
- `ChannelTimeout` if request times out.

```python
result = await ch.request("get_value", timeout=5.0)
```

##### close

```python
def close(self) -> None
```

Close the channel and clean up resources.

## Exceptions

### ChannelClosed

```python
class ChannelClosed(RuntimeError)
```

Raised when interacting with a channel that has been closed.

### ChannelDisconnected

```python
class ChannelDisconnected(RuntimeError)
```

Raised when `request()` has no connected client subscriber. Requests fail
immediately instead of waiting for a timeout.

### ChannelTimeout

```python
class ChannelTimeout(asyncio.TimeoutError)
```

Raised when a channel request times out waiting for a response.

## Type Aliases

### ChannelHandler

```python
ChannelHandler = Callable[[Any], Any | Awaitable[Any]]
```

Handler function for channel events. Can be sync or async.
