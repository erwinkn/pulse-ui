Pulse scheduling runs work in the current render session or app scheduler.
Schedulers are scopes: closing the owner cancels and drains its scheduled work.

```python
from pulse.scheduling import later, repeat, spawn
```

For timers, use the helpers directly from `pulse`:

```python
import pulse as ps

ps.later(1.0, do_something)
ps.repeat(5.0, poll_data)
```

## later

Schedule a callback to run once after a delay.

```python
def later(
    delay: float,
    fn: Callable[P, Any],
    *args: P.args,
    **kwargs: P.kwargs,
) -> TaskHandle[None]
```

`fn` can be synchronous or asynchronous. If it returns an awaitable, Pulse
waits for it before the scheduled task finishes.

The returned anyio `TaskHandle` supports `.cancel()`, `.status`, and awaiting.
Route unmounting does not cancel `later()` callbacks. Cancel the handle when a
route-local callback should not run after unmount.

```python
class NotificationState(ps.State):
    message: str = ""

    def show(self, text: str):
        self.message = text
        ps.later(3.0, self.clear)

    def clear(self):
        self.message = ""
```

## repeat

Run a callback repeatedly at a fixed interval.

```python
def repeat(
    interval: float,
    fn: Callable[P, Any],
    *args: P.args,
    immediate: bool = False,
    **kwargs: P.kwargs,
) -> TaskHandle[None]
```

The first callback runs after the interval unless `immediate=True`. For async
callbacks, the next interval starts after the callback completes. Executions
do not overlap. Callback exceptions are reported through the event loop's
exception handler, and the repeat continues.

```python
class LiveDataState(ps.State):
    data: dict = {}

    def start_polling(self):
        self.handle = ps.repeat(5.0, self.fetch_data)

    def stop_polling(self):
        self.handle.cancel()

    async def fetch_data(self):
        self.data = await api.get_latest()
```

## spawn

Run a coroutine in the active scheduler.

```python
def spawn(
    coroutine: Coroutine[Any, Any, Any],
    *,
    name: str | None = None,
) -> TaskHandle[None]
```

The coroutine's exceptions are reported through the event loop's exception
handler with the task name. Cancellation propagates normally.

```python
from pulse.scheduling import spawn

class BackgroundWorkState(ps.State):
    status: str = "idle"

    def start_work(self):
        self.status = "running"
        spawn(self._do_work(), name="background-work")

    async def _do_work(self):
        await asyncio.sleep(5)
        self.status = "done"
```

Use `Scheduler.spawn()` when you own a scheduler directly:

```python
async with Scheduler("worker") as scheduler:
    scheduler.spawn(work(), name="worker-task")
```

## Automatic cleanup

Scheduling helpers use the current render session's scheduler when called
during a render and the app scheduler otherwise. When the owner closes or
shuts down:

- Pending `later` callbacks are cancelled.
- `repeat` loops are stopped.
- Spawned coroutines are cancelled and drained.

## Event loop

A scheduler binds to the event loop where `await scheduler.start()` runs.
`App.scheduler` starts in the FastAPI lifespan, and a render-session scheduler
starts in `App.create_render`. Handle-returning scheduling from another thread
or event loop, before `start()`, or after `close()` raises `RuntimeError`.

`post(fn)` is the one thread-safe scheduling operation. It accepts a callback
from any thread and runs it on the scheduler's owning loop:

```python
from pulse.scheduling import post

post(refresh)
```

`post()` returns no handle. A `TaskHandle` belongs to the loop that owns it,
so use `spawn()`, `later()`, or `repeat()` on that loop when you need to
cancel or await the returned handle. For other thread integrations,
`anyio.from_thread` can marshal work to the owning loop before scheduling.

## Untracking

Scheduled callbacks run with an untracked reactive context, so reading a
signal inside a timer does not create a reactive dependency:

```python
class State(ps.State):
    count: int = 0

    @ps.effect
    def setup_timer(self):
        ps.later(1.0, lambda: print(f"Count is {self.count}"))
```
